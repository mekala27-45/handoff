## Completed held-out result

Run `model-heldout-v4-1793723921956` finished at `2026-11-03T16:56:31.567Z`. Independent replay verified the sixteen original traces against stored proposals, observed evidence and evaluator truth. All 24 exported files match the retained SHA-256 manifest. The result is 12/16 correct and evidence-complete proposals, three incorrect proposals rejected, and one missing proposal. All sixteen cases made actual tool requests. SQL and authority observations are complete with zero accepted incorrect proposals, review records, approvals or effects.

Two cases proposed refunds where manual review was required. One proposed manual review where a refund was required. Each was rejected for `action_not_allowed` and `missing_required_citation`. A fourth refund case produced no proposal. Missing output remains a failure, not a safe abstention. This is a bounded synthetic experiment, not production readiness or evidence of model execution safety.

The interrupted chat did not interrupt the original workflow. Continuation recovered its completed artifacts without rerunning inference or changing the frozen operating point. V4's 12/16 and v3's 2/16 describe different subsets, with both model and input changes; they do not isolate a causal improvement. Further tuning requires a separate experiment and a newly registered evaluation scope.
